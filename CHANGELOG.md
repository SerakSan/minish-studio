# Minish Studio 7.0.1

- Updated the product name across the interface, app installation metadata, credits, documentation, artwork downloads, and publishing packages.
- Retained SerakSan and the original artwork contributor credits.
- Kept existing scene and animation files, browser autosaves, and preferences compatible.

## Minish Studio 7.0.0

- Renamed the main title to Minish Studio, enlarged it, retained SerakSan, and removed the Scene studio and unofficial studio subtitles from the header.
- Made the canvas larger with narrower panels, lighter game-style frames, compact toolbars, contextual piece actions, and shorter animation cards with visible names.
- Added cursor-anchored trackpad pinch zoom and Ctrl+wheel, plus +, −, 0 for actual size, and F for fit. Ordinary trackpad scrolling still pans. Zoom settles at whole-pixel enlargement.
- Fixed Delete and Backspace from the placed-piece lists. Added in-editor copy/cut/paste, duplication, and layer-order shortcuts while preserving native text editing and Windows/Mac conventions.
- Added visible Delete scene and Delete animation controls with complete Undo. Deleting the final scene or clip leaves a blank canvas in the same format.
- Expanded ready animation to 66 actions across 21 sources, including 38 editor assembly actions across all nine boss families and 202 of 206 supplied complete-boss poses.
- Calibrated fixed boss parts across pose crops, scale, and flips. One-shot transformation actions extend short clips and hold the final supplied pose. Genuine image files and original source artwork remain unchanged.
- Added interface-control regressions for piece-list shortcuts, clipboard data and keys, whole-clip Undo, queued pinch events, and crisp zoom geometry.

## Minish Studio 6.0.0

- Added Simple animation as the default workflow: choose a ready action, set speed and movement, place each piece, and play without editing a timeline.
- Added 32 reviewed ready loops across 15 character, enemy, object, and assembled boss sources. Pose lists use genuine game artwork; timing is authored for the editor, and multipart bosses are labeled editor assemblies.
- Added whole-path placement, exact coordinates, off-frame editing, duplication, clip length in seconds, and an uncluttered Simple playback bar.
- Added Simple dialogue reveal with an editable full message, three speeds, automatic clip extension, and a reading pause.
- Retained Timeline for custom pose sequences, timing, movement, visibility, and component animation. Switching modes preserves custom work; using a ready action over it requires an explicit replacement and supports Undo.
- Replaced the generic workspace thumb with Ezlo moving toward Scene or Animate using seven genuine cap poses, crisp integer scaling, and a reduced-motion alternative.
- Refined the animation library, selected-piece settings, empty state, responsive layout, focus, and keyboard guidance. Scene editing and animation exports remain available.
- Kept artwork without a reviewed action available as still-pose choices with movement and Timeline editing. The collection does not claim every ROM pose or original game timing.
